# Nishant Sourav, a house

My portfolio as a small ink house cut open like a dollhouse. A tiny me lives in it. Choose a room and I walk
there and tell you that part of the story; a notebook beside the house has the details and links.

- **attic**: where I began (electrical engineering, then the switch to software)
- **library**: what I know, as books on the shelves
- **workshop**: what I built: PoweredByAI, Zaprep and EnviroByte, as things on the bench
- **office**: two years at ByteQuest, and the numbers
- **front door**: say hello

In a hurry? `/story` is the whole thing as one plain page.

```bash
npm install
npm run dev      # http://localhost:3000
npm run check    # headless behaviour checks
```

Next.js 16, TypeScript, Tailwind v4 and a hand-drawn Canvas 2D character, with no other runtime dependencies. The
character engine comes from [The Quiet Grind](https://github.com/Remaker00/never-ending-search).
